A static site with an onion backend

Every file here is served by a plain static file server. Paths under duck/ are not files on that server: tor-site.json sends them to DuckDuckGo's onion service, and a Service Worker fetches them through Tor. This page's own code uses ordinary relative URLs and knows nothing about Tor.
