Host an onion service from this tab

This page runs a full Tor client (Arti, compiled to WebAssembly) and can make itself an onion service: a website at a .onion address that anyone with Tor can visit, with no server involved. Visitors never learn your network address, and you never learn theirs. Open this page in two tabs (or two browsers): host in one, visit in the other.

The tab connects to Tor through the Snowflake bridge, like the other demos. Hosting and visiting use the same connection.

The address comes from a secret key kept in this browser (local storage), so it is the same every time you host from here. Anyone who gets that key can host as you; clearing this site's data retires the address. The service is reachable only while this tab is open and online; a background tab can be slow.
